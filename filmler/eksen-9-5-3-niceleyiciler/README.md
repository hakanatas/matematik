# Eksen 9.5.3 · Kırkıncı Adım

*The Fortieth Step* — 9. sınıf matematik, **5. Tema: Algoritma ve Bilişim**

▶ **Filmi izle:** https://hakanatas.github.io/eksen-9-5-3-niceleyiciler/
🧪 **Laboratuvar:** https://hakanatas.github.io/eksen-lab-algoritma/
🗂 **Tüm seri:** https://hakanatas.github.io/eksen-filmleri/

n² + n + 41 ifadesi n = 0'dan 39'a kadar kırk kez art arda asal sayı verir; bir algoritma döngüsü her birine ✓ basar. Kırkıncı adımda 40² + 40 + 41 = 1681 çıkar ve 1681 ışık parçacığı 41'e 41'lik bir kareye dizilir: 1681 = 41². Film buradan yola çıkarak test etmenin ispat olmadığını, tek bir karşıt örneğin "her" önermesini yıktığını, "her tek sayının karesi tektir" önermesinin ise sonsuz bir döngüyle değil tek bir cebirsel hamleyle ispatlandığını gösterir. Aynı önerme sözel, sembolik ve algoritmik dilde yazılır, değili alınır; "ise"nin yönü ve günlük dildeki "veya"nın belirsizliği sembolik dilin yalınlık ve kesinliğiyle karşılaştırılır.

**Tek görsel fikir:** Binlerce test "her" demeye yetmez; tek bir karşıt örnek "her"i yıkar.

- c) Mantık bağlaçları ve niceleyicilerin matematiksel dil ve sembolizmin yalınlık ve kesinliğindeki rolünü değerlendirir.

## Nasıl çalışır? / Çalıştırma

Film tek bir HTML sayfası ve saf JavaScript'tir. Her kare `renderFrame(t)` ile zamanın saf bir fonksiyonu olarak çizilir; rastgelelik tohumludur, ekran kaydı yoktur. Bu yüzden dışa aktarım kare kare ve her seferinde aynı çıkar.

```bash
# Yerelde izlemek için: index.html dosyasını tarayıcıda açmanız yeterli.
npm install            # yalnızca MP4 üretimi için (Playwright)
npm run mp4            # dist/ içine yatay + dikey MP4, SRT'ler ve seslendirme notları
npm run onizleme       # onizleme/ içine kareler + yazı taşma/çakışma denetimi
```

macOS'ta dışa aktarım yüklü Google Chrome'u kullanır (`channel: 'chrome'`) ve `ffmpeg -nostdin` ile kodlar (`brew install ffmpeg`). Uzun işlerde Mac'in uyumaması için `caffeinate -dis npm run mp4` önerilir.

|---|---|

| `film.js` | Sahneler (renderFrame(t) içinde çizilen her şey) |
